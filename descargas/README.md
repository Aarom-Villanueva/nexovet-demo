# NexoVet: entrega revisada de videos y Excel

Descarga `NexoVet-videos-excel-revisado.zip` y sigue `GUIA-WINDOWS-VIDEOS-EXCEL.md`, empezando por el respaldo.

La rama de entrega almacena archivos para descargar. El código actualizado se importa desde el bundle: no clones esta rama para ejecutar la aplicación. La rama dentro del bundle es `fix/videos-excel-validation`, commit `c8fdccdb6f25aa53f0f3d07d34d0bd64670d8a68`; requiere `353b777`.

243 pruebas aprobadas, además de Caddy en dos dominios y el simulacro completo de recuperación en Docker/PostgreSQL 17. Incluye un Excel de ejemplo con datos ficticios.

El bundle no incluye los siete MP4 editados: siguen en tu carpeta de Windows. La guía explica cómo copiarlos para probarlos en local y conectar las URL definitivas de Cloudinary. Privacidad, términos y cookies siguen en borrador. No se ha publicado el producto ni cambiado tu configuración de Gemini.
